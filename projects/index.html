CrowsNest Backend Logic

github
Python, Webscraping, Datascience, MYSQL, Home Server Deployment

This project handles the backend infrastructure of the crowsnest data. Contains a parallel webscraper that collects the latest scores from the official source. Then runs data processing and calculates ratings of every sailor based on the updated races. Finally uploads the new data in an optimized format for storage in the database.
